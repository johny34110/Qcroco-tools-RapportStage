\subsection{Future Prospects}

The future of QcrocoFlow looks promising. For future developers or interns working on this project, several enhancements can be considered:

\begin{itemize}
	\item \textbf{Improving the User Interface:} Making the interface more intuitive and user-friendly.
	\item \textbf{Nested Grid:} This feature would allow generating child and parent grids for the model, thus offering variable resolution across different areas of interest\footnote{Nested grids allow for higher resolution in specific areas of interest while maintaining a lower resolution elsewhere, thus optimizing computational resources.}.
	\item \textbf{Mask Editing:} Add a function to allow users to edit the mask during grid generation, providing more flexibility.
	\item \textbf{Configuring the CROCO Model:} Configuring the CROCO model is a complex process. Integrating a dedicated section in QcrocoFlow to facilitate this step would be of great added value.\\
\end{itemize}

In conclusion, this internship has been a pivotal step in my professional journey. I am grateful for all the learning opportunities and challenges presented to me. I hope my contributions to QcrocoFlow will benefit the scientific community.
